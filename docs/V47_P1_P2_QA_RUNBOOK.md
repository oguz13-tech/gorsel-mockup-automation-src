# V4.7.1 Windows Candidate — P1/P2 verification and safety boundary

## P2 complete in candidate source
- Single UI version identity: `MERKEZ/version_v47.py`. Legacy import file names
  `version_v45.py`, `version_v46.py`, as well as `BASLAT_V46_WINDOWS.bat` and
  `GORSEL_V46_CANDIDATE`, remain as compatibility launchers/names. There are
  not two production workspaces; no user images are moved.
- Cross-store approved template membership now includes a **SHA-verified visual
  dHash** check at assignment. Same SHA was already forbidden. Conservatively
  near-identical dHash (Hamming <= 4) is denied with `MAGAZALAR_ARASI_BENZER_MOCKUP`.
  If any referenced old source image cannot be verified, new assignment fails
  closed with `BENZERLIK_ESKI_ATAMA_DOGRULANAMIYOR`.
  This is a heuristic, not a marketplace uniqueness guarantee.

## P1 hardening and tests completed in code
- Flask review editor: loopback-only host, explicit Origin / Sec-Fetch-Site
  checks; per-process CSRF token for all mutations; dynamic JS wrapper injects
  `X-V47-CSRF` without rewriting existing buttons; X-Frame-Options and
  frame-ancestors deny embedding. The editor continues on `127.0.0.1:8080`.
- Cloud Excel: selected SHA-valid rows only; block files outside local
  `uretilen_gorseller`, reject private localhost HTTPS URLs; dedupe repeated
  receipt rows; atomic known-link reuse and no unauthorised uploads. Real remote
  account credentials and upload cannot be tested in GitHub CI.
- Real-ESRGAN 4K: test subprocess stub verifies exact 1200x1600 input,
  independent receipts, SHA corruption rejection, no output overwrite and
  idempotent repeated run. Windows user's Vulkan GPU / Real-ESRGAN is required
  for physical image-quality acceptance.
- 120 synthetic image batch: STOP after 45, then RESUME with 75 remaining, no
  duplicate ledger keys and independent SHA verification. Real 255 user outputs
  were previously completed and are not regenerated by this test.
- PETEK: real production `unified_batch` invokes
  `PETEK_V3/geometry_qa_v47.inspect_print_safety` before resizing; any pixel
  outside human-approved printable mask changed => fail closed.
  Synthetic 13 vents, top arch, side face and floor labelled ROI test passes.
  **Real vent/curve/side polygon human inspection remains mandatory.** A
  generic approved 2D mask cannot prove there are exactly 13 physical vents
  without trusted manual ROI annotation.
- Cam/Ahşap/PETEK optics: `optical_qa_v47.measure_effect` reports protected
  pixel changes, visible light strength and text-edge perturbation. Synthetic
  six-category A/B envelope passes. **Photographic realism and market-ready
  appearance can only be signed off after visual comparison on the user's
  actual photos**, not with synthetic tests.

## Operator checklist, new ZIP only
1. Stop old service via app, open new version from separate empty folder,
   select exact canonical working folder; do not overwrite historic originals.
2. Verify G3 backup+restore proof before changing profiles.
3. Review PETEK mask / slots / top & bottom curve / floor with representative
   real scene. Use A/B preview for 4 glass categories plus wood/PETEK.
4. Try 4K on one actual 1200x1600 output using the installed Vulkan engine,
   inspect 2880x3840 output physically.
5. Turn on cloud Excel checkbox only after confirming correct hosting account.
   Upload exactly one expendable output first and verify live public HTTPS link
   and SKU row. No fake or shared credentials should be pasted into GitHub.
6. Run long batch on backup-only test workspace before release. Existing
   receipts must remain byte-identical; STOP/RESUME must remain idempotent.
