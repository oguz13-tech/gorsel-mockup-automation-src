# PETEK soft edge + tone harmonization candidate

Bu adayda iki görsel gerçekçilik düzeltmesi yapıldı:
1. Parlak beyaz / nötr açık alanlar sahnenin fotoğrafik panel beyazına yaklaştırıldı.
2. Baskı ile orijinal yüzey birleşim hattında yalnız baskı maskesinin içinde çalışan yumuşak geçiş eklendi.

Notlar:
- Bu değişiklik mağaza atamaları, PETEK 13–16 yarık geometrisi ve A/B test zorunluluğu kaldırma düzeltmeleri üzerine eklenmiştir.
- Orijinal fotoğraf, delikler, kavisler ve onaylı maske kayıtları değiştirilmez.
- Bu paket gerçek Windows kabulü yapılmadan adaydır.
