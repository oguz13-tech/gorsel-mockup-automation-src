# Historical V2 source checkpoint

Sanitized source of the previously delivered V2 center and PETEK commerce bridge.
This is an archival record, **not** the V3 launch target and not a release installer.
Private backup timestamps/configuration, runtime data and user reports are excluded.
`SELECT_VERIFIED_BACKUP` must never be treated as an actual backup path.

V3 starts with `python -m FABRIKA.app`. Its default PETEK route does not use the
procedural 13-slot painter or the archived optional cloud uploader. V2's existing
product-key algorithm is retained for LOCAL/PDK identity compatibility. Other
custom store groups/prefixes require a separate read-only reconciliation before use.
